# 리뷰 감성 분석

한국어 리뷰를 긍정, 부정, 중립으로 분류하고 CSV의 전체 분포를 확인하는 데스크톱 프로그램입니다. 사전과 규칙을 사용하는 방식이며 학습된 언어 모델을 사용하지 않습니다.

## 실행

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe review_dashboard.py
```

가상환경이 이미 있으면 마지막 명령만 실행하면 됩니다. 활성화된 가상환경에서는 `python review_dashboard.py`로 실행합니다. Python 표준 라이브러리만 사용하므로 requirements.txt는 비어 있습니다.

## 사용

- 입력창에 리뷰를 적고 `문장 분석`을 누릅니다.
- `CSV 열기` 후 리뷰가 들어 있는 열을 선택하고 `전체 분석`을 누릅니다.
- 분포 막대, 각 리뷰의 판정과 점수, 일치한 표현을 확인합니다.
- 표의 행을 두 번 클릭하면 리뷰 전체를 볼 수 있습니다.
- `결과 CSV 저장`은 원본 열에 분류, 점수, 근거 표현을 추가해 저장합니다.

UTF-8 및 CP949 CSV를 지원합니다. CSV의 첫 행에는 중복되지 않는 열 이름이 있어야 합니다. 최대 50,000행을 처리하고 화면에는 처음 3,000행을 표시합니다. 결과 저장에는 전체 행이 포함됩니다. 빈 리뷰는 중립과 구분하여 `분석 불가`로 표시합니다.

## 판정 방식

`sentiment_lexicon.json`에 감성 표현과 가중치를 정의합니다. 긴 표현을 먼저 찾아 `불친절`이 `친절`로 중복 처리되지 않게 합니다. 일부 앞뒤 부정 표현, 강조어, `하지만` 등의 접속 표현을 반영합니다. 합계 가중치를 일치한 표현 수의 제곱근으로 나누고 0.65 이상은 긍정, -0.65 이하는 부정으로 분류합니다.

점수는 확률이 아닙니다. 표현이 사전에 없으면 중립으로 분류될 수 있습니다. 반어법, 띄어쓰기 오류, 문맥에 따른 의미 변화와 복잡한 부정 표현에는 한계가 있습니다. 테스트는 규칙의 동작을 검증하며 실제 리뷰 정확도를 측정한 결과가 아닙니다.

`sample_reviews.csv`는 기능 시연을 위해 직접 작성한 20개 예문입니다. 실제 고객의 개인정보나 수집된 리뷰를 포함하지 않습니다.

```powershell
.\.venv\Scripts\python.exe sentiment_checks.py -v
```
